## 1. 产品概述

在线视频播放器——一款对抗百度网盘"倍速播放收费"限制的免费本地视频播放工具。用户可选择本地 MP4 文件，在浏览器中自由调节播放速率（0.25x ~ 4x），无需安装任何软件、无需付费、无需上传文件至云端。

- 核心目标：提供完全免费、无限制的倍速播放体验，打破云盘对播放速率的付费壁垒
- 目标用户：需要快速观看网盘下载视频、在线课程回放、会议录像速览的用户

## 2. 核心功能

### 2.1 功能模块

1. **播放器主页面**：视频画面、播放控制栏、速率选择、文件选择

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 视频播放器 | 视频画面区 | 展示视频画面，支持全屏播放 |
| 视频播放器 | 文件选择器 | 点击或拖拽选择本地 MP4 文件 |
| 视频播放器 | 播放控制栏 | 播放/暂停、进度条、音量控制、时间显示 |
| 视频播放器 | 速率控制面板 | 预设倍速按钮 + 自定义速率滑块，范围 0.25x ~ 4x |
| 视频播放器 | 快捷键提示 | 展示键盘快捷键操作说明 |

## 3. 核心流程

用户打开播放器 → 选择本地 MP4 文件 → 视频加载并自动播放 → 通过控制栏或速率面板调整倍速 → 自由观看

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：沿用平台深色玻璃拟态风格（深蓝底 + 毛玻璃卡片）
- 强调色：视频播放器使用橙红色（from-orange-500 to-red-600）作为主强调色，象征"打破限制"的力量感
- 按钮风格：圆角 12px，渐变背景，hover 时上浮 + 发光
- 字体：Inter + JetBrains Mono（时间码）
- 布局：居中大画面，底部控制栏，速率面板浮于控制栏上方

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 视频播放器 | 视频画面区 | 16:9 比例容器，暗色背景，中央播放按钮 |
| 视频播放器 | 文件选择区 | 虚线边框拖拽区域，点击选择文件按钮 |
| 视频播放器 | 播放控制栏 | 毛玻璃底栏，进度条（橙色）、播放按钮、音量滑块、时间码 |
| 视频播放器 | 速率控制 | 预设倍速按钮组（0.5x 0.75x 1x 1.25x 1.5x 2x 3x 4x）+ 精细滑块 |
| 视频播放器 | 快捷键面板 | 可折叠面板，展示空格/方向键等快捷键说明 |

### 4.3 响应式

- 桌面优先设计，播放器区域自适应宽度，最大 1200px
- 移动端控制栏简化，速率按钮水平滚动

## 4.4 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| 空格 | 播放/暂停 |
| 左方向键 | 后退 5 秒 |
| 右方向键 | 前进 5 秒 |
| 上方向键 | 音量增加 10% |
| 下方向键 | 音量减少 10% |
| F | 全屏切换 |
| M | 静音切换 |
| < | 降低播放速率 |
| > | 增加播放速率 |
